# Browser usability review — 2026-10-13

Scope: existing Workbench, admin navigation, catalogue overview and supplier
degradation review. Frozen sizing, activation and database schemas unchanged.

## Observed in the logged-in production browser (b41d475)

Native Chrome screenshots and accessibility text showed Administrator-Alex,
Caracal / 40MW/80MWh, no active run. The toolbar printed `None`; the admin
entry was below the visible sidebar and required scrolling. Clicking it and
then Degradation opened the real pages. The saved Supplier-2026.10 version was
listed, but the source chooser defaulted to New upload / preview. Selecting
the saved version loaded its curves without re-uploading. Mean selection
updated annual values (Year 1: 95.92% / 94.66% for 1 / 2 cycles per day).

Version details, repeated notes and full-width stacked selectors used two
screenfuls before the plot. SOC was displayed as 50.0; file instructions said
200 MB despite the existing 25 MB parser limit. The catalogue overview said
Phase B / legacy and its 12 curve headers / 0 RTE records were easy to confuse
with active sizing data and the 160 supplier source curves. Old catalogue
headers immediately followed the supplier view.

The browser extension connector failed (`nodeRepl.fetch request failed`).
Native access recovered after selecting/restoring the current Chrome window;
some later screenshots captured another foreground app or inputs were blocked
by detected user input. No action was taken using those mismatched screenshots.
Observed page content and successful clicks are distinguished from incomplete
download/refresh checks.

## Implemented fixes

- Saved versions first; save immediately opens the saved version; duplicate
  uploads offer Open saved version. No data or sizing activation changes.
- Version details, source definitions, source original and catalogue headers
  are separate collapsible sections; source N/A points mean supplier blanks.
- Series / SOC / Power Rate share a row. SOC is shown as 50.00%; plot ticks
  and annual tables show two-decimal percentages. Help explains source labels.
- Selected / all Excel downloads sit together and do not trigger a rerun.
- Frequency selection survives extended-case toggling; hidden high-frequency
  cases are removed from selection. Conditional 24-hour warnings are retained.
- Upload instructions show the actual 25 MB workbook limit and explain the
  Windows file-in-use condition. Existing parser limits remain enforced.
- Catalogue counts are explicitly labelled; catalogue percentages use two
  decimals; source filenames replace server paths in the read-only table.
- Admin entry sits near sign-in controls. Workbench uses Not selected instead
  of None or an empty non-active-run status.
