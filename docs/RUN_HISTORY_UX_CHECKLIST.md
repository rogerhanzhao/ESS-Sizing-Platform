# Run History UX Checklist

1. Open **Projects**.
2. Create a new project and confirm it becomes active.
3. Open **Cases**.
4. Create a new case under the active project and confirm it becomes active.
5. Open **DC Sizing**.
6. Run sizing and confirm a run_id is shown.
7. Open **Run History**.
8. Confirm the new run appears with key summary fields.
9. Click **Restore Run** and confirm DC results populate.
10. Return to **DC Sizing** and confirm the restored results display.
