5.015 MWh 系列深度学习记录（2026-07-18，规格书 + 官网 + 行业盘点）

A. 产品本体

  1. 电气架构：1500 V DC · 314 Ah LFP · 12P416S ≈ 5016 kWh；12 簇 × 4 模组 （每模组 104 芯 ≈104.5 kWh）+ 簇控高压盒——与平台产品库 CALB_5MWh_20FT_12R 完全一致； DC 输出至外部 PCS（DC-Block 形态）。PCS± 推荐单极 6×240 mm² 电缆。
  2. 箱体：20 ft ISO 6058×2438×2896 mm，整重约 45 t；CORTEN A 耐候钢（侧板 2 mm / 底 3 mm）+ 50 mm 岩棉保温；四点底部抽拉式吊点吊装；运输半电量（SOC 30–50%）。CALB 宣称 IP67 与 电芯-Pack-箱体三级防爆（顶部单排 4 块方形泄爆板即箱级泄爆）。
  3. 热管理：全液冷，系统温差 ≤2.5–4 ℃，-30～+50 ℃；液冷机组位于长侧右端镂空舱（CALB 特征位）。
  4. 消防：全氟己酮气体自动灭火 + 水消防接口；CO&H₂&VOC 复合 + 烟感 + 温感 + 防爆型探测器； 声光报警、紧急启停（端面消防面板对应实拍）。
  5. 竞品同规格横评：CRRC CESS 2.0 / Sungrow PowerTitan 2.0 / CATL EnerD / Hithium ∞Block / Trina Elementa 2 全部为 314 Ah + 20 ft + 液冷 5.0–5.016 MWh——外形语言趋同（白箱 + 端部或侧面散热 + 顶部泄爆），CALB 辨识点在侧面镂空液冷舱与单排方形泄爆板。

B. 安装排布

  1. 官方排布能力：CALB 官网明示支持背靠背（back-to-back）与肩并肩（side-by-side）； 海外版 314 Ah 20 ft ISO 宣称省地 22.5%。
  2. 规范依据：GB/T 51048-2025《电化学储能电站设计标准》——步入式预制舱防火间距 长边 ≥3 m、短边 ≥4 m；设防火墙（两端超出舱体 ≥1 m）可豁免间距；2025 版新增 贴邻布置与两层布置条款（即背靠背成对的规范依据）。→ 平台 Site Constraint Set 的 rule_basis 可直接引用本标准。
  3. 电缆路径：辅电、通信、接地、PCS 直流全部从箱底进出线孔敷设 → 基础须留电缆孔洞， 场内以电缆沟连接至 PCS/MVT；接地 ≥2 点、≤1 Ω、禁止串联接地。
  4. 现场惯例（LinkedIn 实拍）：成对镜像门朝外 + 背侧窄缝；对间/排间留防火与检修距； 独立混凝土条形基础高出碎石场坪；MV 撬块或一体舱置排端。

C. 国际（美标 / 英文来源）排布规范 — IFC §1207 · NFPA 855 · NFPA 850 · UL 9540A

  1. 场址分类：Remote Location（距建筑/红线/公共道路/可燃物 >100 ft / 30.5 m）豁免多数间距要求； 否则按 Near Exposures 执行下列间距。
  2. 对外部暴露物间距：BESS 距红线 / 公共道路 / 建筑 / 可燃堆场一律 10 ft（3 m）； 可减至 3 ft（0.9 m）的三条豁免路径——①1 小时独立防火墙（高出并外延 BESS 边界 5 ft）； ②相邻建筑外墙 2 小时耐火无开口；③大规模燃烧测试（UL 9540A）或箱体 2 小时耐火（ASTM E119/UL 263）。
  3. 单元间距：默认 3 ft（0.9 m）；utility 级实践由 UL 9540A 测试 + 辐射热通量建模 （最不利整排全燃工况）确定——这是 Megapack 等能排内紧贴、排间留大通道的合规原理。
  4. 油浸设备间距（NFPA 850）：<500 gal → 5 ft（对 BESS 为 10 ft / 3 m）； 500–5000 gal → 25 ft；>5000 gal → 50 ft；卵石灭火油坑可减至 15 ft。 → 直接影响：美标市场 DC 箱到 PCS&MVT 撬块（油浸变压器）通道应按 ≥3 m 设计， 当前平台默认 2.0 m 仅适用于中国市场/干变场景——布置规则须按市场切换。
  5. 其他：距建筑疏散通道 ≥10 ft；四周 10 ft 清除可燃植被；消防车道按 IFC（宽 20 ft 级）环通或尽端回车； 顶部泄爆板即 NFPA 68 deflagration venting（冰雪地区建议改 NFPA 69 可燃气体机械通风为主，风机需 2 小时后备电源）； 场区消火栓 + 消防水源、首响面板（FRP）、HMA 危害减缓分析是 AHJ 审批前置件。
  6. AC Block 组合基准（2026-07-18 定版）：PCS+MV 按 Sineng EH 系列 / NR PCS-9567MV-5000 产品形态取一体舱（非开放撬块）：NR 5 MW 撬块 = 2 × PCS-9567-2500 twin PCS + MVT + RMU， 持 VDE-AR-N 4110/4120、EN 50549-2、NC RfG 认证；Sineng EH-3200-HA-MR-US-34.5 = 16 × 200 kW 组串式 PCS + LV 柜 + pad-mount 变压器（美标 34.5 kV），EH-12500（40 ft）= 32 × 组串 PCS + 13750 kVA 油浸变、690 V→33 kV、强迫风冷 IP54、-40～+60 ℃。 渲染采用 20 ft 一体舱：组串 PCS 百叶舱 ×3 + 保护/RMU 门（NR 屏柜）+ 变压器散热格栅舱 + 端部 MV 出线箱，DC 箱通道 3.0 m（10 ft）。
  7. 规则引擎启示：排布规范应做成按市场可切换的 rule profile—— CN = GB/T 51048-2025（长边 3 m/短边 4 m/防火墙豁免/贴邻）； US = IFC/NFPA 855 + NFPA 850 + UL 9540A（10 ft 基线/3 ft 豁免/油浸设备分级）； EU/AU = 以 AHJ 与保险商（FM Global 等）要求为准。可作为平台 Site Constraint Set rule_basis 的枚举输入。
