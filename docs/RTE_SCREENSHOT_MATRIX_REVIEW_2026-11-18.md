# 截图式RTE矩阵、测试值填写与自动补表（本地待确认）

本轮按用户要求采用截图中的SOH分段结构。生成的是RTE数据输入表，不修改Stage1/2/3、保证年补箱、原运行时查表或AC公式。新分段会改变RTE输入数据，不能声称结果与旧分段完全相同。

## 初始矩阵怎么得到

100%单列为BOL，之后为95–100%、90–95%直至60–65%，下限包含、上限不含。三列对应截图的0.5P、0.33P、0.25P标签；运行时数值映射继续使用已经配对的原倍率profiles，适用性仍为本地评审假设，不能由截图证明不同P/C定义完全等价。

当前没有新测试值，所以所有初始格子标为`legacy_model`。BOL取已核验旧表值；每个5%区间取旧规则在该区间内实际应用RTE的最小值，避免合并区间时把旧模型变得更乐观。旧单调约束开启、项目RTE修正为0pp用于准备参考表；项目计算仍使用其自身保存的选项。

完整精度结果见`output/curve_upgrade_20261118/screenshot-rte-initial.csv`，管理页面显示4位小数。

## 测试值窗口的计算顺序

1. 管理员选择倍率、SOH节点（100/95/90…60%）、填写RTE百分数，并标明是测试值还是工程输入。空白不是0，不参与校准。
2. 在输入节点保留该值，不偷偷修改它。
3. 同倍率有两个输入节点时，对中间缺失节点按线性插值补表，并标为`interpolated`。
4. 测试范围之外保留旧模型的衰减形状，加上最近输入点的“输入RTE－该点旧模型RTE”差值，标为`legacy_model_calibrated`。这是选定的参考模型校准，不是全寿命实测证明。
5. 若0.25或0.33列已有输入而0.5列没有输入，0.5列按已核验旧关系`RTE0.25 − 1.6 × (RTE0.25 − RTE0.33)`生成，标为`rate_derived`。若0.5列也有输入，则按其自己的输入/插值/校准路径处理。
6. 检查RTE范围、SOH下降时不反向上升、倍率间顺序以及重复输入。冲突时停止并要求核对，不能“修正”测试值让它通过。

这一步的插值用于准备表格。进入SIZING后仍按区间查表，不在原引擎内新增连续插值算法。

示例（仅演示，未作为真实测试值保存）：BOL填0.25P=95%、0.33P=94%，且0.5P未填，0.5P计算为93.4%。如果同倍率H100=95%、H90=93%，则H95补为94%。
